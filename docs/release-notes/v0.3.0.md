# v0.3.0

U03のモデムモードでSMSを受信するための実験的な`u03-sms-receive`を追加しました。

実機では、初期値の内蔵NV優先（`AT+ZSMSD=2`）だとSMSが配送されず、SIM優先（`AT+ZSMSD=1`）へ切り替えると、NTTドコモ網の日本通信SIMで保留中のSMSを含む受信に成功しました。本ツールはPS優先、SIM保存、store-and-notifyを設定し、SIM内のSMSをポーリングして日本語UCS-2とGSM 7-bitを復号します。

SMSは自動削除しません。SIMの保存容量に注意してください。また、本ツールはAPN設定やデータ接続を行わないため、別のMODEMポートで先に回線を接続してください。
