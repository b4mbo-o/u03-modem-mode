au ZTE Speed USB STICK U03（MF871）を元のRNDIS/Web UIモードへ戻せるようになりました。

## 主な変更

- `--to-rndis`による`19d2:1481`から`19d2:1483`への永続的な復帰
- 診断用`19d2:0016`に入った端末の復旧
- ATコマンドごとの成功応答検証
- RNDIS復帰直後にもWeb API認証が通るHostヘッダー対応
- モデムモード／RNDISモード双方の手順とプロトコル資料を更新

モデムモードへの従来の切替は、引き続き引数なしまたは`--to-modem`で利用できます。

```console
sudo ./u03-modem-switch --to-rndis
```

au U03/MF871実機で、直接の`1481 → 1483`と診断状態からの`0016 → 1483`を確認しています。
