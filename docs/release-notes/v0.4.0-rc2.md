# v0.4.0-rc2

Windows向けGUI実行ファイルのリリース候補です。RC1のチェックサム一覧に含まれていた不要なディレクトリ名を修正しました。

- `U03ModemSwitch.exe`単体で起動（PowerShellファイルの同梱不要）
- U03の状態とCOMポートを自動検出
- RNDIS/Web UIから永続モデムモードへ切替
- モデムモードからRNDIS/Web UIへ復帰
- 管理者権限をEXEのマニフェストで要求
- Release assetの検証用`SHA256SUMS.txt`を同梱

> [!WARNING]
> Windows版は実機未検証のプレリリースです。au U03/ZTE MF871以外には使用せず、切替処理中は端末を抜かないでください。`19d2:1484`からの切替には、先に純正ZTEソフトウェアでRNDIS（`19d2:1483`）を出す必要があります。
